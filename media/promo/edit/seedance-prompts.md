# CampusFlow 镜头方案（Seedance Prompt Skill）

参考素材：@图片1 为 CampusFlow 图标；@图片2 为实际周课表截图；@图片3 为 AI 快记截图；@图片4 为成绩分析截图；@图片5 为嘉豪主题截图。参考意味着保留产品身份与色彩，所有界面文字由后期确定性排版叠加。

## 开场材质镜头，6 秒，16:9，60 fps

珍珠白摄影棚，淡紫色轮廓光，镜头从一个有厚度、有折射高光的圆润液体水珠极近特写开始。0–2秒：水珠轻轻变形、回弹并向画面中央滑动，周围两颗小水珠顺着同一轨迹汇聚；2–4秒：液体表面伸展成圆角胶囊，镜头平稳后退，胶囊内显露 @图片1 的产品图标；4–6秒：材质恢复稳定，轻微光线掠过，镜头停在可衔接产品展示的正面构图。柔和精密的产品广告质感，运动连续，没有摇晃。

声音：柔和低频铺底，汇聚时一次轻巧水滴声，成型时一次清脆但不尖锐的 UI 音效。

禁止：随机文字、生成界面文字、真人、闪白、抖动、水印。标题由后期加入。

## 课表镜头，9 秒

参考 @图片2。全周课程卡以清晰底色落位，镜头先从完整手机构图推进到课表。0–3秒：沿今日列微推，强调一周安排；3–6秒：一个半透明触点按住课程，课程仅抬高少许，严格一比一跟随触点移动，目标格出现同色细轮廓；6–9秒：课程准确吸附新格位、缓慢回落，镜头退回整周，保留一秒以上阅读。不要把课程夸张弹飞，其他课程和背景稳定。

## AI 镜头，10 秒

参考 @图片3，午夜紫色舞台。0–3秒：输入“午饭25元，明天下午3点图书馆复习两小时”；3–6秒：输入气泡向上收拢，两个清晰结果卡分别显示消费和日程；6–8秒：确认按钮被轻触，卡片平稳进入对应记录；8–10秒：显示可撤销状态。严谨呈现提取、核对和确认流程。只改变视觉容器，不改金额、时间和原始内容。

## 个性化与嘉豪镜头，8 秒

浅色、蓝色、薄荷色界面通过圆润的滑动胶囊切换，背景图片在同一手机框架内无缝更换。后四秒参考 @图片5，开启嘉豪模式：雨夜紫色背景和独立主题图标依次出现，标题显示“全体嘉豪，往里豪”，最后一秒保持清晰。镜头停止转动，让文字可读。
