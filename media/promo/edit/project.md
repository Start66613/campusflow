# CampusFlow 宣传片制作记录

## Session 1 — 2026-10-12

用户授权：安装 Remotion、HyperFrames、video-use、Seedance Prompt Skill，并按制作者自己的想法直接制作酷炫、全面的宣传视频。

计划：70 秒中文产品片，1920×1080、60 fps，另做适合手机观看的竖屏版本。0–6 秒液态片头；6–12 秒产品首页；12–21 秒周课表与拖动；21–28 秒教务和图片导入；28–38 秒 AI 快记确认；38–47 秒 GPA 口径与有来源的联网分析；47–55 秒番茄钟、记账、周报；55–63 秒 DIY 与嘉豪；63–70 秒日历、提醒、备份和收尾。

技能分工：Seedance 提供中文镜头脚本；HyperFrames 渲染独立液态片头；Remotion 编排主要产品动效；video-use 的 timeline_view 做切点与画面检查。无需原始口播转写，所以这次不要求 ElevenLabs Scribe 密钥。背景音乐为本地原创合成，中文配音优先用 Microsoft 在线语音。

工程事实：App 处于开发预览，原生 iOS 玻璃因系统版本而异，Android 有兼容材质。小组件仍暂停接入。画面使用演示数据，数字与分析不代表用户实际学业。所有主题资源沿用当前项目。

## 最终修正记录

- 横屏片头已有 HyperFrames 烧录品牌/标题，删除主片多余叠字；竖屏使用 contain，不裁断胶囊品牌。
- 手机壳顶部预留 52 px，不用灵动岛压住网页截图标题。
- 课程拖动和换周为可寻帧的产品演示，不伪装为实机帧率测量。
- DIY 浅/深主题采用交叉淡变；AI 确认与撤销、GPA 必修范围等与项目实现核对。
- 最终母带两遍归一化至约 -14.4 LUFS / -1.5 dBTP，AAC 编码后再次测量。
- 初次草稿完成后审片发现片头遮挡，已修正。一次后续渲染因临时服务器嘉豪图标 404 中止，改用经检查的固定 bundle 后重新输出。成片最终验收见 qa-report.md。
