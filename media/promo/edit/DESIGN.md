# CampusFlow — Your campus, in flow

## Style Prompt

Apple-like product-film rhythm with tangible liquid surfaces, calm confidence and large legible Chinese typography. A pearl-white studio with violet material accents turns into a midnight stage for AI. Rounded app surfaces, restrained overshoot, smooth camera-like pushes and match-cut transitions make the product feel tactile. Actual app screenshots and source-faithful animated demonstration UI carry the story; all records are synthetic demonstration data.

## Colors

- Pearl background: #F4F3FA
- Midnight background: #111022
- Ink: #202033
- Brand violet: #655CE8
- Soft mint: #A8DCCD (secondary accent used for study and finance)

## Typography

Microsoft YaHei for Chinese readability on this Windows renderer, Segoe UI for Latin labels, Consolas for small numeric details. Chinese headlines 600/700, no negative Chinese letter spacing. Headlines approximately 84–112px on 1920x1080; secondary copy 34–44px. Real screenshot labels are supplemented by large feature callouts.

## Motion

60 fps. Finger-following visual movement, critically damped spring landings, 0.4-second inter-scene transitions. Light sweeps and droplets move deliberately with feature reveals. Every scene holds its completed state long enough to read. No continuous large bouncing or camera shake.

## What NOT to Do

- No App Store availability claims, fake automatic background payment capture, or working widget claims.
- No real school account, student ID, grades, credentials, or API keys in footage.
- No unreadable generated UI text.
- No frantic glitch transitions, randomly spawning particles, or generic neon sci-fi HUD.
- No changing the main App code or saved user data to make the video.
