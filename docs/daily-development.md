# 日常与成长功能

2026-10-21。本轮从 CampusFlow 的真实课表、待办、番茄钟和个人 AI 接口扩展日常模块。调研参考广州小日常的 [App Store 功能与更新记录](https://apps.apple.com/cn/app/id1263789061)，采用自己的界面与文案，不使用对方素材。

## 本轮可用

- 底部「日常」一级入口，保留首页「我的日常」和「我的 → 日常与成长」快捷入口；四个分区：今日、手记、足迹、心愿。
- 创建及编辑习惯：完成型、计数量、计分钟；星期、间隔天数、起止日期、早午晚、分类、重要标记、图标与颜色、提醒时间。
- 今日/历史日期打卡、量化累计、备注、撤销；归档和恢复、排序；可编辑的习惯灵感库。
- 现有待办统一展示，添加、编辑、完成/取消完成和带确认的删除；未完成项持续保留。
- 手记、五档心情、标题与正文搜索、日期、编辑/删除；内容保存在本机。
- 月历热力图、指定日记录、连续/最长/累计完成、年度月度统计、单习惯及重要习惯筛选。
- 全部当日计划完成解锁日签，翻面、留言与收藏历史。
- 每个习惯每日首次完成赚 5 分；心愿编辑、积分兑换和兑换历史。撤销后再次打卡不重复赚分，归档后不丢失已赚积分。
- AI 快记支持重复习惯，先预览确认再写入，可撤销，防止同一批重复创建；未配置 Key 时保守离线解析。
- 近七天本地复盘；点击按钮才向配置的 DeepSeek 发送习惯与专注汇总。日记正文、心情、照片、备注不进入请求。支持取消、超时、错误回退。
- 日常周报图片预览、手机系统分享、网页保存图片。报告不带习惯名和私密正文。
- 专注倒计时/正计时、自定义时长与休息/轮数、暂停恢复、提前保存、手动补记、历史、关联习惯或待办。计时放到导航上层，按时间戳计算，离开页面不会丢失；休息不计入专注分钟。
- 本机原创合成环境音「轻雨 / 微风」，可单独选择音量和到点提示音。素材可通过 `node scripts/generate-focus-audio.mjs` 复现。
- 手机通知授权后安排滚动 14 天内最近最多 40 条习惯提醒，已完成日期取消；前台返回、数据改变和周期刷新时更新，只管理自己的通知。
- 旧 schema 2 数据增量兼容，完整备份包含新字段。串行保存、恢复前回退副本、损坏数据保留与重试；恢复成功后清理旧计时，避免已完成计时重新注入旧记录。

## 仍需单独完成的功能

本轮不是“小日常所有版本功能已全部复刻”的声明。

- iCloud / 账户云同步、跨设备冲突合并尚未接入；日历同步不等于日常数据同步。目前可导出/恢复 JSON 备份。
- 主屏幕/锁屏小组件、实时活动、Apple Watch 和系统快捷指令未接入本模块，需要独立原生构建、扩展和相应系统能力；Expo Go 不能作为这类扩展的验证依据。
- 系统屏幕使用时间白名单/强制锁机、系统闹钟不在本轮实现范围；目前是本地通知提醒。
- 多成员习惯组、组内拖动、物理小球罐、各类商业插画/字体/付费主题不等同于本轮的自定义分类和奖励系统，尚未实现。
- 网络 AI 的质量、系统后台音频/通知与分享需要 iPhone/Android 真机继续核验；没有在测试中调用用户收费 Key。

`npm run typecheck`；`npm run test:daily`（35 项日常、AI、计时和提醒用例）；`node --test scripts/test-*.mjs`（加入底部日常与后台预览后共 71 项全工程回归）；`npx expo export --platform all --output-dir dist-daily-check`。

底部入口调整后，已在 390×844 验证六个入口可切换、日常无返回键、旧 `/daily` 路径可用；AI 输入框底边仍为 659px，底栏顶边为 775px。8081 原先没有监听，已以隐藏独立进程恢复 Metro；通过 `npm run start:iphone:background` 复用检查，LAN iOS manifest 账号正确、实际 iOS bundle 返回 HTTP 200。手机端仍由用户扫描新二维码完成真机连接验证。

交互核验使用与用户已有 `localhost` 数据隔离的 `127.0.0.1` 测试来源。已实际核对：量化打卡及刷新恢复、日签与留言、积分兑换、手记与心情、AI 离线习惯预览/确认、1 分钟专注自动记录及重新打开后不重复计数、习惯分钟联动、周报 PNG 生成和 390px 窄屏。AI 输入框底边为 659px，底栏顶边为 775px，未重叠。内置浏览器的自动下载事件没有返回，增加可点击/长按的 PNG 预览，并取页面实际生成图片保存、目视检查了文字与图表。验收图位于 `.expo/daily-qa`，不提交测试生活数据。静态导出通过仅说明编译可用，不代替原生真机体验证明。
